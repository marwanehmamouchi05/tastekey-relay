What can this extension read?

Only the current page, after you click the extension and ask it to copy likes or filter results. It does not read browsing history or send page content or likes to a server. Selected likes and settings stay in this browser's extension storage. It does not use cloud sync.

Supported cards include Amazon, Etsy, eBay, Booking, Google Search and sites with article/list cards. Site layouts can change. This filters visible result cards using matching words; it does not change the search engine or promise better results. Filters stop on sign-in and payment forms.
